# DSH Hotkeys

DeepSeek Harness 快捷键增强插件。支持自定义输入框、答案卡片、发送消息等热键操作，提升交互效率。

## ✨ 功能特性

- ⌨️ **全局热键**：支持自定义快捷键唤起输入框。
- 🚀 **快速发送**：一键发送当前选中文本或剪贴板内容。
- 🎨 **UI 增强**：优化答案卡片的展示与交互体验。

## 📦 安装方法

1. 确保已安装 DeepSeek Harness 客户端。
2. 在 Harness 的插件市场搜索 `dsh-hotkeys` 或手动导入本仓库地址。
3. 重启 Harness 即可生效。

## ⚙️ 配置说明

在 Harness 设置中找到 "Hotkeys" 选项卡，即可修改默认快捷键绑定。
